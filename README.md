# Sistema Hospitalario - DevOps

Este repositorio contiene la estructura y el flujo de trabajo DevOps para el desarrollo y control de un Sistema Hospitalario, enfocado en la gestión de pacientes, citas médicas e historiales clínicos.

## Módulos principales:
- Gestión de Pacientes
- Módulo de Autenticación (Login)
- Control de Citas Médicas
